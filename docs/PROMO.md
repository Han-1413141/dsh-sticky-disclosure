## 中文主文案

**一句话**
DeepSeek Harness Web 插件：一键收起所有展开的 Think / 工具卡片；滑出屏幕的标签自动钉在顶部，随时点一下就能收起。

**短文案（适合 V2EX / 知乎 / 微信群）**
对话一长，展开的 Think 思考行和工具卡片就攒了一堆，想收起来还得一个个滚回去点标题。我写了个 DSH Web 客户端插件 [dsh-sticky-disclosure](https://github.com/Han-1413141/dsh-sticky-disclosure)：

- 📌 展开区块滑出屏幕后，标题自动钉在会话顶部，点击 chip 直接收起；
- 🔘 右下角常驻「全部收起」按钮，实时显示 ·N，一键清场；
- ⌨️ 默认 Ctrl+Alt+C，齿轮按钮里按任意新组合键即可自定义；
- 🧩 纯 DOM 实现，不碰应用代码，深色/浅色主题自动跟随；
- ⚡ 一行安装：`dsh plugin --profile web add github:Han-1413141/dsh-sticky-disclosure`

## English copy

**One-liner**
A DeepSeek Harness Web plugin that collapses every expanded Think / tool card in one click — and pins off-screen labels to the top so you can always collapse them.

**Short post**
Long DSH conversations pile up expanded Think rows and tool cards, and collapsing them means scrolling back to each header. I made [dsh-sticky-disclosure](https://github.com/Han-1413141/dsh-sticky-disclosure):

- 📌 Off-screen Think / tool / command labels get pinned to the top as clickable chips;
- 🔘 Always-visible collapse-all pill with a live ·N count;
- ⌨️ Custom hotkey, default Ctrl+Alt+C (⌘⌥C on macOS);
- 🧩 Pure-DOM, zero app-code changes, follows dark/light themes;
- ⚡ One-line install: `dsh plugin --profile web add github:Han-1413141/dsh-sticky-disclosure`
